How exclusions work

Web client layer — exclusions added here prevent the web client from sending those paths to clamd during a full disk scan. For example, adding /proc means the web client will never create a scan job targeting /proc.

clamd.conf layer — for recursive scans (e.g. scanning /var which contains /var/run), clamd itself decides which subdirectories to enter. To exclude subdirectories at that level, add ExcludePath directives to /etc/clamav/clamd.conf:

ExcludePath ^/proc
ExcludePath ^/sys
ExcludePath ^/dev
ExcludePath ^/run
ExcludePath ^/snap

Both layers together give complete control over what gets scanned.
