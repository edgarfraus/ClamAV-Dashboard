Targets are set per-endpoint in Admin › Endpoints (bullseye icon). Defaults cover every real directory (/etc, /home, /var, /usr, …). /proc, /sys, /dev, /run and a bare / or drive root are always skipped, even if manually added as a target — clamd has no way to exclude subpaths mid-scan, so pointing it at one of these can hang the scan.
